## 业务接入与验收

1. 新任务和明确重试的失败任务在提交前，读取完整媒体文件，上传并核对长度与校验结果；生成图优先从现有对象存储读取，保留原件。视频完整下载到临时文件后上传，完成即清理临时文件，不同时在内存堆积多段视频。
2. 按已确定的图片 index 和视频 URL/名称对应关系生成最终列表，全部就绪后一次调用 Ozon 导入。任何一个文件准备失败，这件商品保留生成结果并显示具体文件错误，其他商品继续。绝不按下载完成先后追加图片。
3. 富内容图片、颜色样本和视频封面若实际存在，使用各自原字段和映射，不混入主图库；没有采集到的媒体不能凭空补造。采集来源和冻结快照保留。
4. 首次完整验收先用 SKU 4380440590 的 11 张现有生成图、3 个现有普通视频，在粽子测试01创建独立测试货号 `DIAG-MEDIA-FULL-4380440590-20260915`，无品牌、1555.80 CNY、不设置库存，结束归档；不重用已经归档的两文件测试货号。完整测试及这些额外文件上传尚未得到授权，不能先执行。
5. 完整验收核对平台正式生成的图片数量和顺序、3 个视频处理结果及错误记录。请求返回 task_id 或某个链接 HTTP 200，均不能替代平台验收。若平台仍失败，保留证据继续定位，不盲目重复导入。

## 费用与恢复

正式使用会持续产生存储、请求及外网下载流量费用，取决于商品数量、素材大小和下载次数；本次不购买资源包或预付套餐。北京服务器上传香港 OSS 仍经过自身出口，不能声称升级存储后上传耗时为零。限制媒体准备并发，避免挤占现有 2 核、8GB 服务器资源。

原 Minio 素材保留，既有商品和历史地址不批量迁移。停用新任务的 OSS 接入可回到部署前代码，但已提交的 OSS 文件不能立刻删除或改私有，以免平台后续拉取失败。首次验收前的空资源可以撤销绑定并删除；正式使用后的清理需先核对引用。
