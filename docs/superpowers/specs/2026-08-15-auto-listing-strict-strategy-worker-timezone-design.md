# 自动上架严格类目策略、Worker 与中国时区设计

## 背景

账号当前处于 `LEGACY_FALLBACK` 模式。商品没有精准类目策略时，系统仍会冻结已发布的默认策略，并以 `BALANCED_DEFAULT / DEFAULT` 进入规划。当前任务已经进入 `PLANNING`，但规划消息仍为 `PENDING`、执行次数为 0，原因是自动上架 AI Worker 未运行。

任务创建时间以 `TIMESTAMPTZ` 正确存储为 UTC，前端却直接截取 ISO 字符串，导致 `2026-08-15T11:13:23.454Z` 被显示成 `2026-08-15 11:13:23`，而不是中国时间 `2026-08-15 19:13:23`。

## 业务目标

1. 没有当前 Ozon 类目和类型的精准策略时，禁止创建新的自动上架任务。
2. 当前按默认策略创建的任务不再继续执行，不产生 AI 调用。
3. 自动上架 AI Worker 恢复运行，为后续合规任务消费规划队列。
4. 自动上架页面的任务时间统一按 `Asia/Shanghai` 显示。

## 已确认方案

采用方案 B：先取消当前任务，再启用严格类目策略模式，随后启动 Worker；用户在“类目图片策略”页面配置精准策略后重新创建任务。

### 执行顺序

1. 读取当前任务和状态版本，确认仍处于可取消的 `PLANNING` 状态。
2. 通过正式任务取消接口执行取消，携带当前状态版本、幂等键和关联 ID。
3. 验证任务进入 `CANCELLED`，并确认其规划消息不会被 Worker 消费。
4. 通过正式类目策略设置接口将账号模式从 `LEGACY_FALLBACK` 更新为 `REQUIRE_EXACT_STRATEGY`，保留版本与审计证据。
5. 启动自动上架 AI Worker，验证其进程和队列连接健康。
6. 以 TDD 修复前端时间格式化，并刷新页面验证。

顺序不可交换：Worker 必须在旧任务取消后启动，避免旧任务在取消前触发 AI 调用。

## 策略边界

- 严格模式只允许精确匹配当前 `taxonomyScope + descriptionCategoryId + typeId` 的已发布规则。
- 缺少精准策略时，创建接口返回现有安全错误 `AUTO_LISTING_CATEGORY_STRATEGY_REQUIRED`，不进入仓库验证、AI、对象存储或任务图写入。
- 系统不自动猜测或生成类目策略。策略内容由用户在“类目图片策略”页面配置并发布。
- 已取消任务保持原有冻结策略和事件证据，不改写历史。

## 任务取消与队列安全

- 取消操作走现有后端权限和状态机校验，前端按钮不作为权限依据。
- 使用任务 ID、条目 ID、当前状态版本、幂等键和关联 ID，确保重复操作不产生重复状态变更。
- 取消后必须存在可追溯的状态事件。
- Worker 读取到已取消或版本不匹配的任务时必须拒绝执行，不能调用 AI。

## 时间显示契约

- 数据库与 API 继续使用标准 UTC ISO 时间，不修改表结构或 API 字段。
- 仅展示层将有效 ISO 时间转换为 `Asia/Shanghai`，格式固定为 `YYYY-MM-DD HH:mm:ss`。
- 无效、空或缺失时间仍显示 `—`。
- 该规则同时用于任务创建时间、任务进度更新时间和下一次重试时间，避免同一页面出现混合时区。

## 测试与验收

### 自动化测试

- 时间格式测试先证明当前 UTC 截取行为失败，再实现 `Asia/Shanghai` 转换。
- 覆盖 UTC 跨日转换、无效时间和空值。
- 回归自动上架页面、视图模型、状态机、任务路由和类目策略相关测试。

### 本机验收

- 当前旧任务状态为 `CANCELLED`，规划消息未被执行，内容方案数量仍为 0。
- 账号策略模式为 `REQUIRE_EXACT_STRATEGY`，版本递增且有审计记录。
- 自动上架 AI Worker 正在运行。
- 未配置精准策略时，新任务创建被阻止。
- 页面将 `2026-08-15T11:13:23.454Z` 显示为 `2026-08-15 19:13:23`。

## 影响范围与回滚

- 代码影响：自动上架前端时间展示函数及其测试。
- 配置影响：当前账号的类目策略模式。
- 运行影响：启动一个自动上架 AI Worker 进程。
- 数据影响：当前任务按正式状态机进入 `CANCELLED`；不删除任务、事件、快照或队列证据。
- 不涉及数据库迁移、Ozon 写入、库存修改或商品创建。

回滚时，时间显示代码可通过 `git revert` 恢复；策略模式如需恢复，必须通过正式设置接口并使用当前版本更新；已取消任务不做历史回写，应在完成精准策略后创建新任务。
