# 类目图片策略详情返回列表设计

## 目标

在“类目图片策略”详情页右上角提供明确的“返回策略列表”按钮。点击后必须稳定显示策略列表，不能因为 URL 查询参数或自动上架恢复记录而重新打开原草稿。

## 最小方案

- 按钮仅在当前存在策略详情时显示，与已有“返回自动上架”和“刷新”按钮并列。
- 点击后先使当前异步加载或写操作的后续 UI 更新失效，再清空当前详情、样本、会话、分析、发布版本和表单状态。
- 删除当前账号在 `sessionStorage` 中的自动上架类目策略恢复记录。
- 导航到 `/ozon/tools/category-strategies`，不保留 `draftId`、`from` 或其他查询参数。
- 列表数据继续使用现有 `client.list()` 和现有表格，不新增路由、状态管理层或依赖。

## 保持不变

- 不修改后端 API、数据库、权限、多租户、样本、发布或幂等规则。
- 不删除草稿或服务器数据；清除的只是当前浏览器标签页的自动恢复意图。
- “返回自动上架”与已发布后的“返回并继续创建”行为保持不变。

## 验收

1. 详情页显示“返回策略列表”，列表页不显示该按钮。
2. 点击后导航地址精确为 `/ozon/tools/category-strategies`。
3. 当前账号的自动恢复记录被删除，原草稿不会自动重新打开。
4. 当前详情状态被清空，页面显示“类目策略列表”。
5. 原有类目策略页面测试、生产构建和浏览器预览通过。
