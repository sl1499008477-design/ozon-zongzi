# 删除选品与水印功能设计

**日期：** 2026-07-30  
**状态：** 已选择方案 A，等待书面规格确认

## 1. 目标

从当前项目中完整删除两组业务功能：

1. 选品：Web 端选品菜单及其全部页面、插件端选品推荐与榜单采集能力、后端选品专用接口。
2. 水印：Web 端水印管理页面、插件端全部水印配置与上架参数、后端水印模板接口及活动状态字段。

同时保留 AI 工具本身，只删除菜单旁的蓝色“推荐”标签。

完成后，用户界面不再出现选品或水印入口；旧页面地址进入现有 404 页面；旧专用接口不再存在；插件安装包不再包含选品或水印专用能力。

## 2. 已确认的业务规则

- 采用“彻底删除”方案，不使用隐藏、功能开关或保留不可达死代码。
- Web、插件、后端三个运行面同时删除，避免只删页面而保留后台副作用。
- 普通的商品勾选、表格行选择、店铺选择、类目选择等通用交互不属于“选品功能”，必须保留。
- 商品销量、销售额、库存、类目等正常经营数据仍服务商品管理和经营分析，不能因字段或注释中出现“选品”而删除。
- AI 改图、AI 商品套图、AI 重写等功能保留，只移除 AI 工具菜单旁的“推荐”标签。
- 当前本地 JSON 状态和 PostgreSQL `local_state` 中：
  - 水印模板数量为 0；
  - 店铺水印绑定数量为 0；
  - 选品历史报告数量为 0。
- 因当前不存在活动数据，本次无需执行数据备份或业务数据迁移。
- 已有通用审计记录不按关键词批量删除，继续满足可追溯要求。

## 3. 方案选择

### 方案 A：彻底删除（采用）

删除所有明确属于选品和水印业务的入口、页面、路由、消息、接口、资源文件、样式和测试夹具，并增加反向契约测试，防止功能以后被旧代码或打包副本重新带回。

优点：

- 与用户目标完全一致；
- 减少死代码和维护成本；
- Web、插件、后端能力边界一致；
- 不再产生选品快照、水印模板或水印上架参数。

代价：

- 旧页面和旧接口不再兼容；
- 已安装的旧版插件必须更新，才能与删除后的后端合同完全一致。

### 未采用方案

- 只隐藏入口：仍保留后台能力和死代码，不满足“整套删除”。
- 功能开关：增加额外配置和分支，违反 KISS，并非真正删除。

## 4. Web 端设计

### 4.1 删除选品

删除以下路由及页面：

- `/ozon/selection/category`
- `/ozon/selection/top-list`
- `/ozon/selection/china`
- 旧别名 `/ozon/selection/market`
- 旧别名 `/ozon/selection/rank`

`/ozon/selection/profit` 当前指向订单利润趋势，不属于选品业务页面。删除该旧别名，但保留正式利润趋势页面 `/ozon/postings/profit-trend`。

同时删除：

- 左侧“选品”菜单及三个子菜单；
- 仪表盘“类目分析”“榜单选品”入口；
- `CategoryPage`、`SelectionListPage`；
- 仅为这些页面服务的数据转换、筛选和排序方法；
- 仅为这些页面服务的 CSS。

旧地址通过现有 `normalizePath` 规则进入 `/404`，不自动跳转到其他业务页面。

### 4.2 删除水印

删除以下路由及页面：

- `/ozon/tools/watermark`

同时删除：

- “工具”菜单中的“水印管理”；
- 仪表盘“水印管理”入口；
- `WatermarkPage`；
- 水印模板编辑、图片预览、批量下载和 Canvas 绘制逻辑；
- 仅为水印页面服务的 CSS。

“工具”菜单继续保留“浏览器插件”。

### 4.3 删除“推荐”标签

将 AI 工具菜单标题恢复为普通文本“AI 工具”，不删除其两个子页面，也不改变 AI 功能路由。

## 5. 插件端设计

### 5.1 删除选品专用能力

删除：

- 商品详情页“选品推荐”按钮；
- 热卖榜单、蓝海商品、中国卖家推荐面板；
- `getRecommendations` 消息；
- `fetchBestsellers` 消息及选品快照上报；
- `reportCategoryMapping` 消息；
- `ozon-bestsellers-hook.js`；
- `ozon-seller-bridge.js` 中仅服务类目映射上报的分支；
- Manifest 中 Bestsellers 页面专用注入配置；
- 选品推荐面板专用样式。

保留：

- 商品数据卡中的正常销量和销售额数据；
- 通用市场数据查询；
- 商品采集、跟卖、利润计算、以图搜图、主题标签等其他按钮；
- `ozon-seller-bridge.js` 中 Premium 透视眼等非选品能力。

不存在实际代码的旧“选品模式”注释应删除或改成准确描述，但不能因此删除搜索页采集和数据面板。

### 5.2 删除水印专用能力

删除：

- 插件弹窗“水印管理”入口；
- `lib/watermark-templates.js` 及 Manifest 引用；
- 单品上架和批量上架中的水印开关、模板选择器、缺失模板校验；
- `applyWatermark`、`watermarkTemplateId`、`watermarkText` 等水印专用配置和消息参数；
- 水印专用 CSS；
- 服务工作线程中水印模板读取逻辑；
- 与上述能力对应的测试夹具和路由断言。

保留 AI 改图和 AI 重写。删除水印后，这些 AI 选项仍能独立展开、保存和提交。

## 6. 后端设计

删除水印接口：

- `GET /ozon/watermark-settings`
- `POST /ozon/watermark-settings`
- `PUT /ozon/watermark-settings/:id`
- `DELETE /ozon/watermark-settings/:id`

删除选品接口：

- `POST /ozon/selection/bestsellers/snapshot`
- `POST /ozon/selection/category-mapping`

删除活动状态合同中的：

- `caches.watermarkTemplates`
- 水印模板数量摘要；
- 对外店铺对象中的 `watermarkTemplateId`。

状态加载需要兼容旧文件：旧状态即使仍带有上述字段，运行时也必须忽略且不再向客户端返回；下一次正常保存时不再写出这些活动字段。不得通过关键词删除其他报告或审计数据。

被删除的接口使用现有未知路由行为返回 404，不保留功能专用处理器或功能开关。

## 7. 稳定合同与错误处理

- Web 旧路由：显示现有 404 页面。
- 后端旧接口：返回现有统一 404 响应。
- 新版插件：不再发送任何已删除消息或接口请求。
- 旧版插件：调用旧接口时会收到 404；本次不增加兼容层，因为用户明确要求彻底删除。
- 插件核心采集、Web 登录桥、账号级采集箱和后端同步合同不得改变。
- 上架请求不再包含任何水印参数，但其他 AI 参数和上架幂等合同保持不变。

## 8. 测试设计

实施遵循测试先行：

1. 先添加删除契约测试，并确认它会因现有代码仍存在而失败。
2. 最小化删除生产代码，使测试通过。
3. 执行完整回归。

删除契约至少验证：

- Web 菜单、路由、快捷入口和页面定义中不存在选品与水印业务入口；
- AI 工具菜单不存在“推荐”标签，AI 页面仍存在；
- 原 Web 地址进入 404；
- 后端原专用接口不再命中处理器；
- 插件 Manifest 不再包含 Bestsellers hook 或水印模板脚本；
- 插件服务工作线程不再接受选品和水印专用消息；
- 插件弹窗和上架界面不再出现水印入口或选项；
- 商品采集、账号级采集箱、AI 改图、AI 重写、经营数据展示仍通过现有回归测试；
- 源码和打包后的插件均通过反向残留扫描。

最终验证包括：

- 定向删除契约测试；
- Web 生产构建；
- 插件 Manifest、语法、打包和能力门禁；
- 项目完整 `scripts/verify.mjs`；
- 浏览器检查左侧菜单、仪表盘入口、404 行为以及 AI 工具菜单；
- 后端健康检查和被删除接口的 404 检查。

## 9. 风险与控制

### 风险：误删通用选择逻辑

控制：测试和扫描只针对明确的业务路由、消息名、组件名、CSS 前缀和资源文件，不对 `selection`、`select` 等通用词做全局机械删除。

### 风险：水印删除影响 AI 上架

控制：保留 AI 改图和 AI 重写的独立参数与展开逻辑，增加无水印条件下的上架合同回归。

### 风险：源代码删除但打包副本残留

控制：重新生成插件分发目录和 ZIP，并对源目录、分发目录、Manifest 和服务工作线程同时扫描。

### 风险：旧插件继续调用已删除接口

控制：新版插件完全移除调用；旧版插件收到统一 404。交付说明明确要求重新安装新版插件。

## 10. 回滚

- 代码回滚通过 Git 反向提交完成，不重写已共享历史。
- 若删除后发现依赖关系遗漏，恢复本次删除提交即可恢复页面、接口和插件资源。
- 当前没有水印模板、店铺水印绑定或选品历史报告，因此不存在需要单独恢复的活动业务数据。
- 回滚后重新构建插件并重启本地服务，恢复原路由与 Manifest。

## 11. 验收标准

- Web 左侧不存在“选品”菜单。
- Web 中不存在类目分析、榜单选品、中国专区和水印管理入口。
- AI 工具保留，旁边不显示“推荐”。
- 原选品和水印 Web 地址进入 404。
- 插件中不存在选品推荐、水印管理、水印开关或模板选择。
- 后端不再提供选品和水印专用接口。
- 插件包中不再包含 Bestsellers hook 或水印模板脚本。
- 普通商品选择、店铺选择、采集、账号级采集箱、AI 改图、AI 重写、Web 后端同步继续工作。
- 完整验证无失败，并明确记录未验证范围。
