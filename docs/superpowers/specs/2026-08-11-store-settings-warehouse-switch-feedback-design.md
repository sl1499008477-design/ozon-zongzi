# 门店仓库数量与切换反馈设计

## 目标

修复门店设置页的两个可见问题：每个门店显示其自身的本地仓库数量；切换门店期间立即展示持续进度、阻止重复提交，并在请求结束时给出明确结果。

## 范围与约束

- 仓库数量按仓库记录中的门店标识归属，不再使用账户总仓库数，也不因门店未激活而显示 `—`。
- 当前门店摘要中的仓库数同样只统计当前门店。
- 一次只能切换一个门店。目标按钮显示“切换中…”，其他切换按钮禁用。
- 进度消息持续到后端切换、刷新本地状态全部完成；成功或失败消息替换同一条进度消息。
- 不修改数据库、后端接口或门店同步业务规则，不在验证中实际切换用户门店。

## 结构

`stores-settings-model.js` 负责把门店与仓库投影为稳定的每店计数和表格行；页面只渲染该投影。`store-switch-gate.js` 负责内存中的单航班门禁，`App.jsx` 负责真实切换请求、React 状态和消息反馈。这样计数规则与并发门禁都能脱离浏览器做行为测试。

## 错误处理

找不到门店或目标已经是当前门店时不进入切换状态。切换请求或刷新失败时清除门禁并显示失败；成功时更新绑定、持久化当前门店并显示成功。任何重复点击在第一个切换完成前都被拒绝，不产生第二个 HTTP 请求。

## 验证

- 单元测试验证两个门店分别显示 `33` 和 `1`，当前摘要为 `33`。
- 单元测试验证重复切换只执行一个异步操作，完成或失败后门禁均释放。
- 相邻门店设置、运行时与构建回归通过。
- 浏览器只读确认渲染结果；不点击真实“切换”按钮。
